# First Home Plan: value-first funnel

Live route: https://kareemjamaltherealtor.com/first-home-plan
Campaign keyword: READY. Keep HOME (general buyer) and PLAN (seller) distinct in the tracker.

## Offer and path

Social content about one renter's question -> next-step selector -> useful, ungated checklist -> optional First Home Clarity Session request -> personal reply -> mutually agreed call -> one action, owner, and review date.

This is our real-estate application inspired by Acquisition.com's Lead Magnet Mastery training (https://www.acquisition.com/training/leads3). It is not an endorsement, reproduction of the book, or a promise of more leads. Solve a narrow planning problem first; make requesting help easy and specific. No invented monetary value, client results, testimonials, urgency, or lending guarantees.

## What is implemented

- Six English/Spanish next-step checklists; save as a local text file without providing contact details.
- Open access to the existing bilingual journal and fillable action guide.
- Short inquiry: name, email, explicit permission for one reply. Other context is optional.
- Selected topic and suggested first step included in the existing Formspree request.
- Campaign and UTM fields included. Browser dataLayer event hooks are present; a reporting backend is not verified.
- Response states distinguish an accepted request from a confirmed appointment.

## What remains manual or unverified

- Real form delivery and inbox receipt require a genuine submission and confirmation.
- CRM entry, appointment booking, reminders, agreed follow-up dates, and lead records are not connected by this change.
- No DMs, email campaigns, social posts, or ads are sent or scheduled.
- Kareem personally reviews warm conversations and follow-up dates. Do not start a marketing sequence from permission for one reply.

## Next controlled test

Compare two social hooks for the same tool: (A) cash needed to buy, (B) work-history uncertainty. Keep destination, format, audience context, and CTA consistent. Use utm_content=cash-hook or income-hook. Do not claim a winner without observed visits and attributed valid inquiries; reach alone cannot measure form conversion.

Track verified counts by source and week: landing visits, tool engagement (if instrumented), valid inquiries, booked calls, attended calls, agreed actions due, agreed actions completed. Separate READY/HOME/PLAN. Rate denominators: valid inquiries / landing visits; booked calls / valid inquiries from that cohort; attended / calls due; completed actions / actions due. Never treat the exposed event hooks as recorded results.

90% admin reduction = (baseline admin minutes - current admin minutes) / baseline admin minutes, measured for the same work volume and scope. Exclude client calls and property visits. Leave it unknown until a recorded baseline and comparable current measurements exist.

## Five-item operating checklist

1. Confirm a genuine form inquiry reaches the correct inbox and includes topic/campaign fields.
2. Choose and connect the CRM, then test deduplication and failure alerts before enabling automatic entry.
3. Add booking and reminders only after verifying availability and consent rules.
4. Record one next action, owner, due date, and permission for further follow-up after each conversation.
5. Review actual conversion counts and comparable admin time weekly before scaling distribution or ads.

## Planning-ahead intake — October 18, 2026

The form now defaults to a personal email reply for people planning ahead; a visitor can instead request a 15-minute conversation or help finding a starting point. This is client intent, not a lending-readiness rating.

Initial-reply permission is separate from the optional request for one later personal email check-in. A date is required only when the visitor chooses the later check-in. No recurring education, SMS, appointment, reminder, or drip campaign is authorized or installed by either choice. Kareem confirms details personally. If the visitor cancels, record the pause and do not follow up again.

Minimum handling after a real inquiry: deduplicate; preserve source/campaign/topic/intent; record actual initial reply; agree one task, owner, completion evidence, and review date/channel or pause. Keep any private financial worksheet with the client. Preserve READY/HOME/PLAN routing. A far-off buying window should receive the same respectful help; do not use language preference to infer eligibility.
